Cómo calcular y dibujar el área bajo una curva

  1. Escribe una función de x, por ejemplo x^2.
  2. Indica dónde empieza y termina el intervalo, por ejemplo 0 y 2.
  3. Elige cuántos rectángulos usar o indica el ancho de cada rectángulo.
  4. Calcula la integral y muestra los rectángulos para ver cómo se aproxima el área.

Para probar una función trigonométrica, elige la unidad de los ángulos antes de calcular.

Para el ejemplo de x^2, el área exacta es 8/3. Usa el resultado como referencia al cambiar el número de rectángulos.

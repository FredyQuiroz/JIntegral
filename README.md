# JIntegral

[Español](#español) · [English](#english)

## Español

Calculadora gráfica para entender las integrales. Dibuja una curva y estima el área bajo ella sumando rectángulos, una forma visual de acercarse al resultado matemático.

### Esta revisión

**2009-05-21 · Visualizar el área bajo una curva.** Evalúa la función indicada y dibuja los rectángulos que aproximan su integral en un intervalo. Al variar el número de rectángulos se puede comparar el cálculo numérico con la gráfica.

### Cómo explorar el código

El código se creó para Windows y Visual C++. Usa las versiones de MFC o de los SDK que indiquen la solución y sus referencias. Los recursos y componentes externos de la época pueden requerir una copia autorizada. La compilación completa depende de ese entorno original.

- [JIntegral/JIntegral.vcproj](JIntegral/JIntegral.vcproj)

## English

A graphical calculator for learning about integrals. It draws a curve and estimates the area below it by adding rectangles, making the mathematical calculation visible.

### This revision

**2009-05-21 · Visualize the area under a curve.** Evaluate the entered function and draw the rectangles approximating its integral over an interval. Changing the rectangle count lets users compare the numerical estimate with the graph.

### How to explore the source

The code was written for Windows and Visual C++. Use the MFC and SDK versions indicated by the solution and its references. Historical resources and external components may require an authorized copy. A full build depends on that original environment.

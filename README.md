# JIntegral

[Español](#español) · [English](#english)

## Español

Calculadora gráfica para entender las integrales. Dibuja una curva y estima el área bajo ella sumando rectángulos, una forma visual de acercarse al resultado matemático.

### Qué puedes hacer

- Permite indicar una función y el intervalo que se quiere analizar.
- Dibuja la curva y la aproximación mediante rectángulos.
- Permite explorar cómo cambia la estimación al variar el número de rectángulos.

### Ejemplo

Compara en un mismo intervalo el área estimada con pocos rectángulos y con más rectángulos. Observa qué parte de la gráfica se aproxima mejor.

## English

A graphical calculator for learning about integrals. It draws a curve and estimates the area below it by adding rectangles, making the mathematical calculation visible.

### What you can do

- Lets you enter a function and the interval to analyze.
- Draws the curve and its rectangular approximation.
- Lets you explore how the approximation changes with the number of rectangles.

### Example

Compare the estimated area over the same interval with fewer and then more rectangles. See which parts of the graph are approximated more closely.

### Getting started

The code was written for Windows and Visual C++. Use the MFC and SDK versions indicated by the solution and its references. Historical resources and external components may require an authorized copy. A full build depends on that original environment.

Entry points in the source. [`JIntegral.sln`](JIntegral.sln), [`JIntegral/JIntegral.vcproj`](JIntegral/JIntegral.vcproj).
